# AI CEO OS v1

Claude-centered autonomous AI operating system.

## Mission
Turn high-level goals into autonomous research, implementation, review, measurement, and iteration while escalating only high-impact decisions to Furkan.

## Core roles
- Claude: AI CEO / Orchestrator / decision maker
- Comet: web research and browser operations
- Codex: engineering review, testing, security and regression checks
- Creative agents: visual and content production
- Furkan: final authority for irreversible, financial, strategic and brand-critical decisions

## Operating loop
1. Receive goal
2. Inspect context and memory
3. Break goal into tasks
4. Delegate to the correct agent
5. Review outputs
6. Execute low-risk work autonomously
7. Test and verify
8. Measure outcome
9. Learn and update memory
10. Escalate only when approval is required

## Permission model
GREEN: autonomous execution.
YELLOW: execute in a reversible branch/draft and request approval before release.
RED: never execute without Furkan approval.

See `docs/` and `config/` for the operating system specification.
